Project overview

We developed an ICU-hour-level early warning model using MIMIC-IV clinical data to forecast sepsis onset within a 1–4 hour window. The approach combines hourly measurements with latent multimorbidity phenotypes to capture differences between patients.

The poster describes a pipeline of SQL cohort extraction, hourly feature engineering, patient-grouped train/test splitting, preprocessing, and a 500-tree random forest classifier. The model prioritizes sensitivity to reduce missed cases.
